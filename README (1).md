
# Digital Queue Management System

## About the Project

Digital Queue is a smart campus queue management website designed to make student access to college services simpler and more organised.

## Features

- Student name entry
- Campus service selection
- Demo token generation
- Responsive purple-themed user interface
- Home, Services and How It Works sections

## Technologies Used

- HTML
- CSS
- JavaScript

## Campus Services

- College Office
- Library
- Accounts Section
- Department Office

## How to Run

1. Download or open the project folder.
2. Open index.html in a web browser.
3. Enter a student name.
4. Select a campus service.
5. Click Generate Token.

## Current Status

The frontend demo is working. Tokens are generated in the browser and are not yet saved to a database.

Java backend and MySQL integration will be added by the project team.
